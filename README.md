# HighlightOutline

AffinityPluginLoader plugin. Right-click a layer > Tools > Highlight Outline adds an
Inner Shadow FX (radius 0, offset 10, intensity 0, fill opacity 0) with an Affinity's native Layer Effects dialog (colour picker,
opacity, angle, radius...). Apply rasterises the layer without preserving layer FX.

Install: put `HighlightOutline.dll` in `apl/plugins/` of the Affinity install and launch via `AffinityHook.exe`.
